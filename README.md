# 💬 Real-Time Chat App (Frontend)

A responsive React application powered by **Vite**, featuring real-time messaging via **Socket.io**, secure authentication, and a modern interface for seamless user communication.

## 🛠 Tech Stack

* **Framework:** React.js (Vite)
* **Language:** JavaScript (ES6+)
* **Real-Time:** Socket.io Client
* **HTTP Requests:** Axios
* **State Management:** React Context API (Auth & Socket)
* **Styling:** CSS / Tailwind (Update this based on what you used)
* **Deployment:** Vercel

## ✨ Features

* **⚡ Instant Messaging:** Real-time bidirectional communication using WebSockets.
* **🔐 Secure Auth:** Login, Registration, and OTP Verification UI.
* **📱 Responsive Design:** Optimized for both desktop and mobile devices.
* **🔔 Live Notifications:** Visual cues for new messages and connection status.
* **🟢 Online Status:** Real-time visibility of user availability.
